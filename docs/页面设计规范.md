# 学生简历页面设计规范

## 1. 设计边界

项目固定的是视觉系统、交互和输出质量，不固定学生的内容结构。不同专业、经历和申请方向可以使用不同章节、顺序和信息密度。

所有学生页面必须保留：

- 统一页面宽度、留白、字体和灰阶。
- 统一语言切换、PDF 下载与回到顶部控件。
- 统一中英文排版体系。
- 统一 A4 打印规则。
- 统一标题、条目、日期、地点、列表和附注的基础视觉语言。

以下内容由每名学生单独决定：

- 是否需要个人简介。
- 章节名称、数量和顺序。
- 教育、研究、项目、作品、展览、临床、竞赛、实践或其他专业内容的表达方式。
- 每个章节采用条目、列表、网格或短段落。
- 中英文版本的信息侧重点。

## 2. 页面结构

每名学生使用一个独立文件：`resumes/<slug>.tsx`。

正式学生通过 `cohort` 与 `slug` 拼成单段公开路径，例如 `cohort: "27"`、`slug: "zhiyuan"` 对应 `/27zhiyuan`（两段之间没有斜杠，对外短链更紧凑）。不填写 `cohort` 时使用 `/<slug>`，用于 `/demo` 等特殊页面。

页面必须使用 `ResumeDocument` 作为根节点。优先复用以下基础组件：

- `ResumeHeader`：姓名、简介和联系方式。
- `ResumeSection`：章节容器。
- `ResumeEntry`：机构、项目、角色、地点和日期。
- `ResumeBullets`、`ResumeBullet`：成果与职责。
- `ResumeNote`：课程、技术栈和补充信息。
- `ResumeGrid`、`ResumeGridRow`：技能或分类信息。
- `ResumeInline`：语言能力等短行信息。

组件是视觉约束，不是内容模板。AI 应按内容需要自由组合、重复或省略组件。

## 3. 视觉规范

- 页面保持白底、单色、中性灰阶，不使用装饰性色块。
- 不为每个章节增加卡片、阴影或背景容器。
- 控件（下载 PDF、回到顶部）统一为纯描边、透明填充、无阴影，不做主次分级，共用 `.btn`；方形纯图标控件另加 `.btn--icon`。
- 阴影在全站仅保留一处：语言切换器的选中药丸（`.langtoggle button.is-active`）。那里的浮起是在表达「选中」状态，属功能性用法；除此之外控件一律不得引入阴影。
- 不添加无必要的分隔线；章节标题下划线是主要结构线。
- 英文正文使用 Libre Baskerville，姓名使用 Cormorant Garamond。
- 中文使用 Inter 与 Noto Sans SC，不使用斜体。
- 打印字号在 `@media print` 内以 **pt** 定义（贴近打印语境，便于讨论与核对），但**取值必须是 0.75 的整数倍**。Chrome 永远按 px 布局，`pt` 只是入口单位（`4px = 3pt`）：写 `10pt` 会被转成 `13.333…px`、舍入成 `13.33`，输出后实际是 `9.9975pt`；写 `13.5px` 则换算成 `10.125pt`。两个方向都可能脏，光换单位并不能解决。**改字号前先做 `pt ÷ 0.75` 这道除法，得整数 px 才可用**：9(12px) / 9.75(13px) / 10.5(14px) / 11.25(15px) / 12(16px) / 13.5(18px) / 18.75(25px) / 21(28px)。
- 当前打印阶级：姓名 21pt（中文名 18.75pt）/ 分节标题 13.5pt / 条目标题 10.5pt / 正文 9.75pt / 联系方式 9pt，正文行距 1.35。校验方法：PDF 内容流里的 `Tf` 操作符原始值应全部是整数（那是 px，Puppeteer 输出带 0.75 缩放矩阵）。
- 字号一律走 `--text-*` 令牌，不在规则里硬编码 px/pt。令牌必须有实际引用，不保留「备用档」——没人用的令牌会连同注释一起腐化成假文档。
- 调整打印密度优先动**行距**而非字号：实测行距 1.42→1.35 与字号 10pt→9.5pt 的空间收益相同，但行距不牺牲字号可读性。
- 信息层级主要依靠字号、字重、留白和对齐，不依靠多层灰色文本。
- 机构或项目与地点两端对齐；角色或学位与日期两端对齐。
- 列表圆点、文本基线和跨页位置必须保持稳定。
- 新增局部布局时复用 `app/globals.css` 的设计令牌，不硬编码新的颜色体系。

## 4. 内容与文字规范

- 忠于材料，不补写无法核实的事实。
- 先突出与申请方向最相关、最能证明能力的内容。
- 要点优先采用「动作、方法、结果」结构，并保留可靠的量化信息。
- 中文与英语或数字之间保留一个半角空格。
- 中文使用直角引号「」，英文使用弯引号“”。
- **中文版不给机构 / 项目附加英文名括号。** 有通行中文名就只写中文名（澳门理工大学、腾讯、中国农业银行 北京市分行）；只有英文名通行的直接拿英文名当标题（如 ZONST Data Group），不必硬凑中文。括号里的英文名基本只是中文名的直译，不提供额外信息，反而挤占标题行——学生自己起的项目名（FYP、课程项目）更是没有可检索的正式英文名。若条目有 `href`，读者点开即可确认，更不需要括号。
- `ResumeEntry` 的 `titleSuffix` 参数用于标题后的括号补充，两类用途：机构资质标注（如「双一流 A 类、985 工程」），以及上一条之外「中英文名缺一不可识别」的罕见情况（默认不用）。传 `titleSuffix` 必须同时传 `lang`，组件按语言自动取全角（中文）或半角（英文）括号，**页面内不要手写括号**。
- 公司 / 机构名用**官方全称**，不用简称，且须核到官方来源。无法核实官方中文名时保留英文原名，不音译。注意区分易混实体（如 SJM Holdings = 澳門博彩控股有限公司、Sociedade de Jogos de Macau S.A. = 澳門博彩股份有限公司、SJM Resorts S.A. = 澳娱综合度假股份有限公司，三者不同）。
- 不使用「·」堆叠标签或身份信息。
- GPA、排名、考试成绩和单位按原始材料呈现。
- 英文版不残留中文；中文版可以保留必要的英文专有名词。

## 5. 双语与打印

- 英文版为默认页面，中文版通过 `?lang=zh` 访问。
- 两个版本可以使用不同章节顺序和不同内容密度。
- 学生页面不自行实现语言按钮或下载按钮。
- PDF 使用当前页面的 HTML 与 `@media print` 输出，不维护另一套模板。
- 每次新增页面必须检查 A4 分页、孤行、标题跨页和链接显示。

### PDF 文件名

对外发送的 PDF 统一为 `<名字>_CV_<语言>_<年月>`，下划线连接：

| 语言 | 名字取值 | 示例（2026 年 8 月） |
| --- | --- | --- |
| 英文 | `names.en` 的名（去括号昵称，Title Case）；单字名补姓 | `Zhiyuan_CV_EN_2608.pdf`、`Xin_Chen_CV_EN_2608.pdf` |
| 中文 | `names.zh` 全名（去空格） | `林知远_CV_ZH_2608.pdf` |

年月为导出当时的 `YYMM`，不是简历定稿日期。

`names.en` 必须写成**名在前、姓在后且姓全大写**（`Zhiyuan LIN`、`Xin CHEN`），文件名规则据此取首词为名。写成 `Lin Zhiyuan` 会得到以姓命名的 `Lin_CV_EN_2608`。

补姓判定：`names.zh` 是两个字（姓 + 单字名，如陈昕）时，英文单字名（Xin）过于含糊，追加姓氏成 `Xin_Chen`；三字中文名的双字名（Zhiyuan）单独成名即可辨识。无中文名的学生一律只取名。带括号昵称的英文名（`Junhong (Jason) QIAN`）先去掉括号部分再取名。

文件名规则**只在 `components/ResumeSwitcher.tsx` 一处计算**，两个出口都消费它：

1. **网页下载按钮**（学生实际用的那条）——`window.print()` 让浏览器「另存为 PDF」，默认文件名取自 `document.title`。`ResumeSwitcher` 算出 `fileName`，`components/DownloadButton.tsx` 在打印前临时改 `document.title`、`afterprint` 还原。
2. **CLI 批量导出**——`scripts/render-pdf.mjs` 覆盖 `window.print` 后点击页面上的真实下载按钮，抓打印瞬间的 `document.title` 作为落盘文件名。CLI 不自己拼名字，改规则只改 `ResumeSwitcher`。

这也意味着 CLI 每次运行都在验证下载按钮的文件名（同一条代码路径）；单独手工验证时用同样的手法：

```js
await page.evaluateOnNewDocument(() => {
  window.__t = null;
  window.print = () => { window.__t = document.title; };
});
// 打开页面后 click 下载按钮，再读 window.__t
```

文件名不依赖 slug——slug 只影响 URL，不影响导出文件名。

## 6. 验证要求

每次新增或修改学生页面后至少完成：

1. `npm run lint`。
2. `npm run build`。
3. 桌面端英文和中文页面检查。
4. 窄屏布局检查。
5. A4 打印预览或 PDF 检查。
